Getting started
  • Add a file using + Add or drag files into the left panel from your desktop.
  • Include the file extension so we know how to run it — e.g. Main.py, script.sh.
  • For Python and shell scripts, if you only need extra parameters enter them in the Execution Command field above (e.g. --verbose) or for a full custom command, include the filename too (e.g. python3 -u main.py --flag).
  • For Markdown/AI agent files, enter the complete CLI command.
  • Separate parameters with spaces; wrap values containing spaces in double quotes (e.g. --output "/tmp/my file.csv").
